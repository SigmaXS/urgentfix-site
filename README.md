# UrgentFix — лендинг

## Заявки в Telegram

Обе формы отправляют заявку через `netlify/functions/submit-lead.js`.
Успех и событие Google Ads показываются только после подтверждения `sendMessage`.
Это подтверждает доставку заявки, а не состоявшийся звонок или личность клиента.

Перед публикацией добавьте в Netlify переменные окружения, доступные Functions:

- `URGENTFIX_TELEGRAM_BOT_TOKEN` — токен бота `@MY_MOLDOVA_BOT`.
- `URGENTFIX_TELEGRAM_CHAT_ID` — числовой ID личного чата получателя `@sigmalxl`.

Получатель должен сначала нажать «Старт» в боте. Токен хранится только в
закрытых настройках хостинга; не добавляйте его в репозиторий или браузерный JS.
Не публикуйте изменения до настройки и проверки доставки тестовой заявки.
Проверки без реальных отправок: `node --test tests/lead.test.cjs`.

Адаптивный лендинг для компании/мастера по ремонту газовых котлов и мелким сантехническим работам (аварийный выезд, Кишинёв).

## Структура

```
santehnika-site/
├── index.html      — разметка страницы (Tailwind CSS через CDN)
├── css/style.css    — дополнительные стили и анимации
├── js/script.js      — интерактивность: мобильное меню, вкладки цен,
│                         модальное окно, scroll-reveal, переключатель RU/RO
└── img/             — папка для изображений (пока пусто, использованы SVG-заглушки)
```

## Запуск

Просто откройте `index.html` в браузере — внешние зависимости (Tailwind CSS, шрифт Inter, иконки Lucide) подключаются через CDN, локальный сервер не требуется.

Для деплоя достаточно загрузить содержимое папки `santehnika-site` на любой статический хостинг (Netlify, Vercel, GitHub Pages, обычный shared-хостинг).

## Возможности

- Адаптивная вёрстка (mobile-first), sticky CTA-панель на мобильных
- Переключатель языка RU / RO (весь текстовый контент вынесен в словарь в `js/script.js`)
- Вкладки с ценами по категориям услуг
- Модальное окно заказа обратного звонка
- Форма заявки/калькулятора
- Плавные scroll-reveal анимации через IntersectionObserver

- Карту-заглушку (SVG в разделе «Контакты») — на встраиваемую карту (Google Maps / Яндекс Карты iframe)
